# 🧠 Sabixão - Sistema Universal de Conhecimento Multimodal

O **Sabixão** é um ecossistema analítico híbrido de conhecimentos gerais projetado para resolver desde questões simples até problemas de alta complexidade. Ele opera integrado com visão computacional para leitura de telas, arquivos e câmeras (PC/Mobile), utilizando uma arquitetura resiliente estilo **Hidra de Lerna** com varredura invisível.

---

## 🛠️ Como Ligar o Cérebro Real (Configuração de Chaves Gratuitas)

Para que o Sabixão pense com inteligência real e imediata, você precisa pegar suas duas chaves de acesso gratuitas. Siga o passo a passo:

### 1. Chave do Google Gemini (Análise Profunda)
1. Acesse o site do [Google AI Studio](https://google.com).
2. Faça login com qualquer conta Google (Gmail) convencional.
3. Clique no botão azul **"Get API key"** (Obter chave de API).
4. Clique em **"Create API key"** e copie o código gerado (ele começa com `AIzaSy...`).

### 2. Chave da Groq LPU (Velocidade Instantânea)
1. Acesse o painel do [Groq Console](https://groq.com).
2. Faça login com seu e-mail.
3. No menu esquerdo, clique em **"API Keys"**.
4. Clique em **"Create API Key"**, dê o nome de "Sabixao" e copie o código gerado (ele começa com `gsk_...`).

## 🚀 Como Executar o Sabixão na Sua Máquina

Com os arquivos baixados do seu GitHub para o seu computador, abra o terminal na pasta do projeto e execute os seguintes comandos:

### Passo 1: Instalar as Dependências do Sistema
Instale todas as ferramentas gratuitas listadas no arquivo `requirements.txt`:
```bash
pip install -r requirements.txt
```

### Passo 2: Instalar o Navegador Invisível (Playwright)
Execute o comando abaixo para que o motor de buscas oculte o navegador automático na máquina:
```bash
playwright install
```

### Passo 3: Injetar as Chaves de API no Sistema
No terminal da sua máquina (Windows), defina as chaves criadas para que o código as reconheça com segurança:
```bash
set GEMINI_API_KEY=sua_chave_do_gemini_aqui
set GROQ_API_KEY=sua_chave_da_groq_aqui
```
*(Se estiver utilizando Linux ou Mac, use o comando: `export GEMINI_API_KEY="sua_chave"`)*

### Passo 4: Iniciar a Interface Web e Mobile
Agora, ligue o painel visual do Sabixão executando o Streamlit:
```bash
streamlit run app.py
```

O terminal exibirá um link local (Ex: `http://localhost:8501`). Abra esse link no navegador do seu PC ou transfira para o celular na mesma rede para começar a escanear e resolver qualquer problema do mundo!
